# MarketFlow Pipeline Protocol

Here is a comprehensive protocol for running your pipeline, designed for clarity and organization.

## Phase 1: Initial Setup and Data Preparation

Data Collection: Ensure you have high-quality OHLCV (Open, High, Low, Close, Volume) data for the stocks you wish to analyze. The data should be in CSV format.

Configuration: Verify that the marketflow_config_manager.py module is correctly configured with the paths to your data and report directories.

## Phase 2: Batch Analysis

Purpose: The marketflow_batch_analysis.py script is your starting point. It analyzes multiple stocks, generates individual reports, and creates a consolidated Transient Vector Memory (TVM) for querying.

Execution: Open your terminal or command prompt and run the script with the ticker symbols you want to analyze as arguments.

Bash

python marketflow_batch_analysis.py TICKER1 TICKER2 TICKER3
Example:

Bash

python marketflow_batch_analysis.py AAPL TSLA NVDA
Output: This script will generate a batch output directory containing:

Individual ticker analysis folders with detailed reports.

A consolidated TVM store (.tvm_store) and a namespace file (.tvm_namespace).

A batch summary CSV file.

## Phase 3: Monte Carlo Simulation (Risk Assessment)

Purpose: The marketflow_monte_carlo_trade.py script simulates trade outcomes to assess the probability of success for your long positions.

Execution: This script can be run in two modes:

Single-Run Mode: To analyze a specific trade setup from the most recent data point.

Bash

python marketflow_monte_carlo_trade.py "path/to/your_ticker_annotated.csv" --tp <take_profit_price> --sl <stop_loss_price>
Example:

Bash

python marketflow_monte_carlo_trade.py ".marketflow/reports/2025-09-23/AAPL/AAPL_1d_wyckoff_annotated.csv" --tp 210.5 --sl 203.0
Backtest Mode: To evaluate the model's performance over historical data.

Bash

python marketflow_monte_carlo_trade.py "path/to/your_ticker_annotated.csv" --simulate-backtest --bt-tp-pips <take_profit_pips> --bt-sl-pips <stop_loss_pips>
Example:

Bash

python marketflow_monte_carlo_trade.py ".marketflow/reports/2025-09-23/AAPL/AAPL_1d_wyckoff_annotated.csv" --simulate-backtest --bt-tp-pips 5.0 --bt-sl-pips 2.5
Output: For each run, this script generates:

A JSON summary file with metrics like Probability of Profit (POP).

Interactive HTML plots (fan chart and histogram of time-to-hit).

## Phase 4: Visualization and Interpretation

Purpose: The plot_annotated_features.py script provides a suite of visualizations to help you interpret the analysis from the previous steps.

Execution: Run the script with the path to an annotated CSV file generated by marketflow_analysis.py.

Bash

python plot_annotated_features.py "path/to/your_ticker_annotated.csv"
Example:

Bash

python plot_annotated_features.py ".marketflow/reports/2025-09-23/AAPL/AAPL_1d_wyckoff_annotated.csv"

Optional explicit Monte Carlo overlay:

Bash

python plot_annotated_features.py ".marketflow/reports/2025-09-23/AAPL/AAPL_1d_wyckoff_annotated.csv" --mc-summary ".marketflow/reports/2025-09-23/AAPL/20250923_120000_mc_summary.json"
Output: This script will generate and display several interactive plots, including:

An annotated Wyckoff Candlestick chart.

A Volume Profile chart.

A Point & Figure chart.

Other feature plots (spread, volume class, etc.).

Interpretation: Use these charts to visually confirm the signals and patterns identified in the analysis. Look for confluences between the Wyckoff phases, VPA signals, and Monte Carlo probabilities to make your final trading decisions. A strong long setup would typically show:

The stock in Phase D of an accumulation pattern.

A recent "sign of strength" (SOS) on high volume.

A high Probability of Profit from the Monte Carlo simulation.

A clear breakout on the Point & Figure chart.
